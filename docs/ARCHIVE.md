## 第二版范围

归档当前已经接入官网的最终成果，形成可以独立安装、运行和构建的项目。保留现有页面组成、交互、文字和运行素材；不将历史研究页面作为额外的官网入口发布。

| 正式入口 | 保留内容 |
| --- | --- |
| `/` | 五秒开屏、粒子叙事、真实地球、液态银色视觉、三张价值卡及合作表单与页脚 |
| `/training/robot-data/` | 18 个真机场景、机器人与任务条件选择、第一人称样例及加工展示、数据基础设施 |

| `/about/` | 经营理念、连接与协作、团队、联系与合作四幕，以及共享导航和联系模块 |

第一人称公开样例保持本次归档前的现有版本，包括现有 36 条样例；素材来源说明一并保留。三维任务状态与公开样例的说明沿用当前页面和来源记录，不把示意表达写成实际采集或模型训练结果。

第二版包含已定稿的「关于刻行」。此前排除该页的决定适用于第一版归档时的开发状态。未接入的历史研究入口、比较方案、临时环境和构建产物不在本次范围。正式首页同位置的旧结束版本已移除；共享导航指向实际页面和章节。

正式页面依赖的一些源文件沿用 `study` 名称。这些文件保留，因为首页、训练页面和交付演出实际使用它们；文件名不代表本仓保留了对应的独立研究入口。

关于页开场保留远程 Wix 参考媒体引用，来源见 [关于页参考说明](archive/about-reference.md)。首页与关于页合作表单只做本地验证，提示「信息尚未发送」；未接入外部收集接口。机器人动作、任务场景和 Illustrative 曲线沿用当前实现边界。

## 构建与发布

2026-10-10 在独立代码仓执行 `npm run lint`、`npm run build` 和 `node --test scripts/test-miniature-batch.mjs`，均通过，现有模型测试为 3 项。107 个正式依赖源文件、857 个素材文件及 6 个 HTML 入口与最新工作目录的 SHA-256 一致；887 个正式构建文件也与定稿目录的构建产物逐文件一致。36 条视频样例的 108 项媒体引用、169 项模型运行资源及 15 份静态记录完整。

本次没有重新执行历史完整浏览器矩阵或真实设备验收；定稿目录的桌面和手机检查见上述历史接入记录。构建仍保留现有 Three.js 大分块提示，字体和图片的构建期路径提示由运行素材复制步骤解决。

使用 Node.js 24 与 npm，按 README 执行安装、检查和构建。正常构建只输出上述六个正式 HTML 入口。`generate-quality-delivery-records.mjs` 生成静态阅读页，`copy-production-public.mjs` 与 `miniature-production-assets.mjs` 复制动态加载素材及对应模型、字体许可。

公开归档用于分享代码和版本成果，不会自动部署官网、变更正式域名或替换线上页面。表单后台也不属于此次归档操作。
