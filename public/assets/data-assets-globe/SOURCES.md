# Data Assets Globe Study Sources

- Active Earth day master image: NASA Blue Marble Next Generation, August 2004, `https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-topography-bathymetry/august/world.topo.bathy.200408.3x21600x10800.jpg`
  - Local responsive derivatives: `earth-day-summer-8k.jpg`, `earth-day-summer-4k.jpg`, `earth-day-summer-2k.jpg`
- Previous winter comparison image: NASA Visible Earth, Blue Marble Topography and Bathymetry, December 2004, `https://eoimages.gsfc.nasa.gov/images/imagerecords/73000/73909/world.topo.bathy.200412.3x21600x10800.jpg`
- Earth night master image: NASA Earth Observatory, Black Marble 2012, `https://eoimages.gsfc.nasa.gov/images/imagerecords/79000/79765/dnb_land_ocean_ice.2012.13500x6750.jpg`
  - Local desktop derivative: `earth-lights-4k.jpg`
  - Existing mobile texture: `https://threejs.org/examples/textures/planets/earth_lights_2048.png`
- Earth cloud master image: `https://raw.githubusercontent.com/turban/webgl-earth/master/images/fair_clouds_4k.png`
  - Local desktop derivative: `earth-clouds-2k.png`
  - Existing mobile texture: `https://threejs.org/examples/textures/planets/earth_clouds_1024.png`
- Earth elevation texture: `https://raw.githubusercontent.com/turban/webgl-earth/master/images/elev_bump_4k.jpg`
  - Local responsive derivatives: `earth-elevation-4k.jpg`, `earth-elevation-2k.jpg`
- Earth water mask: `https://raw.githubusercontent.com/turban/webgl-earth/master/images/water_4k.png`
  - Local responsive derivatives: `earth-water-4k.png`, `earth-water-2k.png`
- Prototype administrative boundaries: `https://geo.datav.aliyun.com/areas_v3/bound/`

The administrative boundary files are used only for the internal visual study. Replace or validate them against an approved authoritative map source before public deployment. Review all image-source licensing and attribution requirements before public deployment.
